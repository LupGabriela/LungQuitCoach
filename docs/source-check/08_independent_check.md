6. **Section 1.4.5 (E3 design): "each participant reads four fixed fictional cases, each with a different explanation type (checked LLM text; template with an icon array; and, if possible, unrestricted LLM text) … With four positions, the number of participants must be a multiple of four, so the target is 32 or 36". The same logic appears in Appendix A ("so that the 4×4 Latin square is balanced").**
   Problem: this is internally inconsistent. Only 2–3 explanation types (conditions) are listed, so four cases cannot each get a different type. A balanced Latin square is built over conditions, not cases. With 3 conditions (odd), a balanced design needs 6 orders, so N should be a multiple of 6. With 2 conditions, N should be a multiple of 2. The "multiple of four" rule holds only for 4 conditions.
   Evidence: report lines 98 and 206; 05_eval_methods.md §6 (Acheson: "each condition is immediately preceded once by all other conditions"; its note assumes 4 conditions); lab34.txt §3.2.2 item 6 ("each explanation type, each on a different fictional case (4 fixed cases …)").
   Fix: either define a fourth condition (e.g. template without icon array, or a numbers-only text), or decouple cases from conditions: counterbalance the condition order with a Latin square over 3 conditions and the case–condition pairing separately. Then restate N.
