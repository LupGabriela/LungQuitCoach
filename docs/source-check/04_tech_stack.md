# 04 – Technology stack: choice and motivation (verified 18 Nov 2026)

Thesis: **Lung Health & Quit Coach**, a research prototype web app (UBB, CS licență).
Target machine: Intel Core 7 150U, 16 GB RAM, **no NVIDIA GPU**, Windows 11 + WSL2. Must run offline.

## How this was verified

- **Versions and dates:** taken from the PyPI JSON API (`https://pypi.org/pypi/<name>/json`, the same data as `https://pypi.org/project/<name>/`), the npm registry (`https://registry.npmjs.org/<name>`), or official git tags (`git ls-remote` plus the tag's commit date). The date is the upload or tag date of the latest stable version.
- **Facts:** taken from official docs, mostly fetched as raw source from the official docs repositories on GitHub (`github/docs`, `docker/docs`, `huggingface/hub-docs`, `MicrosoftDocs/WSL`, `superfly/docs`, `jenkins-infra/jenkins.io`, `caddyserver/website`, `letsencrypt/website`, `ollama/ollama/docs`, `vllm-project/vllm/docs`) and from official web pages where they could be reached.
- **Blocked:** the GitHub REST API (releases endpoint) was not reachable. Where the table says "tag", the version is the newest stable git tag and the date is that tag's commit date. That date may differ by a few hours or days from the "published" date on the GitHub release page.
- Everything I could not confirm is listed in the "Could not verify" section at the end.

### Deployment plan (based on the facts above)

1. **Local (primary target):** `git clone` → `wsl --install` (if missing) → Docker Desktop (WSL 2 backend) → `docker compose up` with services `api` (FastAPI + Uvicorn + torch CPU + TorchXRayVision), `cxr-lung-risk` (separate image with its own pinned environment, or ported weights), `ollama` (`ollama/ollama` image, `ollama pull qwen3:4b`) and `frontend` (Vite build served statically).
